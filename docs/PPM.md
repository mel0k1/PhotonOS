# ppm — Photon Package Manager

`ppm` — фирменный пакетный менеджер PhotonOS. Под капотом — честный **apt**
Debian, а сверху — короткие команды, цветной вывод, проверки прав и
ASCII-логотип. Никакой магии и никаких прослоек с кэшем: каждая команда
прозрачно транслируется в вызов `apt-get`/`apt-cache`/`dpkg-query`, код
возврата сохраняется.

## Установка

На PhotonOS `ppm` уже установлен (попадает в образ при сборке ISO). На другую
машину с Debian можно поставить вручную:

```sh
sudo install -Dm755 ppm/ppm /usr/bin/ppm
```

Зависимость одна — сам apt (уже есть на любой Debian-системе).

## Команды

| Команда                 | Действие                              | Транслируется в                |
| ----------------------- | ------------------------------------- | ------------------------------ |
| `ppm install <пакеты>`  | обновить индексы и установить         | `apt-get update` + `apt-get install` |
| `ppm remove <пакеты>`   | удалить пакеты и их сироты            | `apt-get remove` + `apt-get autoremove` |
| `ppm search <запрос>`   | поиск по описаниям в репозиториях     | `apt-cache search`             |
| `ppm info <пакет>`      | подробности о пакете                  | `apt-cache show`               |
| `ppm sync`              | синхронизировать индексы репозиториев | `apt-get update`               |
| `ppm update`            | полное обновление системы             | `apt-get update` + `apt-get full-upgrade` |
| `ppm autoremove`        | удалить пакеты-сироты                 | `apt-get autoremove`           |
| `ppm clean`             | очистить кэш скачанных пакетов        | `apt-get clean`                |
| `ppm list`              | список установленных пакетов          | `dpkg-query -W`                |
| `ppm about`             | версия и логотип                      | —                              |
| `ppm help`              | справка                               | —                              |

Синонимы: `i` = `install`, `r`/`rm` = `remove`, `s` = `search`, `up` = `update`,
`ls` = `list`.

## Особенности

- **Прозрачность.** Аргументы не парсятся и не фильтруются, работают все
  флаги apt: `ppm install -t trixie-backports firefox`.
- **Проверка прав.** Команды, которым нужен root, сразу подсказывают:
  `нужны права root: sudo ppm install`.
- **Чистый stdout.** Служебные сообщения `ppm` идут в stderr, поэтому вывод
  apt можно спокойно направлять в пайпы и скрипты.
- **Код возврата.** `ppm` возвращает код возврата вызванной утилиты apt —
  удобно в скриптах автоматизации.
- **NO_COLOR.** Цвет отключается стандартной переменной `NO_COLOR`, а также
  автоматически, если stdout — не терминал.
- **Без рекомендаций.** Образ идёт с `APT::Install-Recommends=false`
  (`overlay/etc/apt/apt.conf.d/99-photon-no-recommends`): пакеты ставятся
  тем же минимальным составом, каким собран ISO — принцип слабых ПК.

## Примеры

```sh
# классический цикл: синк, обновление, установка
ppm sync && ppm update
ppm install firefox fonts-noto-core

# поиск и изучение пакета
ppm search terminal
ppm info qterminal

# уборка: сироты и кэш
ppm autoremove
ppm clean
```

## Философия

apt — отличный движок, но его команды (`apt-get`, `apt-cache`, `dpkg`) не
едины и непривычны людям, приходящим с других дистрибутивов. `ppm` не
заменяет apt и не отходит от него ни на шаг — он просто даёт единый вход и
человеческие названия. В любой момент можно вызвать apt напрямую.
