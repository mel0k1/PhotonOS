# ppm — Photon Package Manager

`ppm` — фирменный пакетный менеджер PhotonOS. Под капотом — честный **XBPS**
от Void Linux, а сверху — короткие команды, цветной вывод, проверки прав и
ASCII-логотип. Никакой магии и никаких прослоек с кэшем: каждая команда
прозрачно транслируется в вызов `xbps-*`, код возврата сохраняется.

## Установка

На PhotonOS `ppm` уже установлен (попадает в образ при сборке ISO). На машину
с Void Linux можно поставить вручную:

```sh
sudo install -Dm755 ppm/ppm /usr/bin/ppm
```

Зависимость одна — сам XBPS (уже есть на любой Void-системе).

## Команды

| Команда                 | Действие                                | Транслируется в   |
| ----------------------- | --------------------------------------- | ----------------- |
| `ppm install <пакеты>`  | установить пакеты                       | `xbps-install -S`   |
| `ppm remove <пакеты>`   | удалить пакеты вместе с зависимостями   | `xbps-remove -R`    |
| `ppm search <запрос>`   | поиск по описаниям в репозиториях       | `xbps-query -Rs`    |
| `ppm info <пакет>`      | подробности о пакете                    | `xbps-query -R`     |
| `ppm sync`              | синхронизировать индексы репозиториев   | `xbps-install -S`   |
| `ppm update`            | полное обновление системы               | `xbps-install -Su`  |
| `ppm autoremove`        | удалить пакеты-сироты                   | `xbps-remove -O`    |
| `ppm clean`             | очистить кэш скачанных пакетов          | `xbps-remove -m`    |
| `ppm list`              | список установленных пакетов            | `xbps-query -l`     |
| `ppm about`             | версия и логотип                        | —                   |
| `ppm help`              | справка                                 | —                   |

Синонимы: `i` = `install`, `r`/`rm` = `remove`, `s` = `search`, `up` = `update`,
`ls` = `list`.

## Особенности

- **Прозрачность.** `ppm install -y firefox` передаст `-y` в xbps как есть:
  аргументы не парсятся и не фильтруются, работают все флаги xbps.
- **Проверка прав.** Команды, которым нужен root, сразу подсказывают:
  `нужны права root: sudo ppm install`.
- **Чистый stdout.** Служебные сообщения `ppm` идут в stderr, поэтому вывод
  xbps можно спокойно направлять в пайпы и скрипты.
- **Код возврата.** `ppm` возвращает код возврата вызванной утилиты xbps —
  удобно в скриптах автоматизации.
- **NO_COLOR.** Цвет отключается стандартной переменной `NO_COLOR`, а также
  автоматически, если stdout — не терминал.

## Примеры

```sh
# классический цикл: синк, обновление, установка
ppm sync && ppm update
ppm install firefox noto-fonts-ttf

# поиск и изучение пакета
ppm search terminal
ppm info qterminal

# уборка: сироты и кэш
ppm autoremove
ppm clean
```

## Философия

XBPS — отличный движок, но его CLI с трёх утилит (`xbps-install`,
`xbps-remove`, `xbps-query`) непривычен людям, приходящим с других
дистрибутивов. `ppm` не заменяет XBPS и не отходит от него ни на шаг — он
просто даёт единый вход и человеческие названия. Дистрибутивная независимость
сохранена: в любой момент можно вызвать xbps напрямую.
